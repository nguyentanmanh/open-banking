# open-banking

Generated by HexaForge as a Java 21 / Spring Boot 3.5.16 single-module hexagonal service.


```bash
./mvnw clean verify
./mvnw spring-boot:run -Dspring-boot.run.profiles=local
```

- Swagger UI: <http://localhost:8080/swagger-ui.html>
- OpenAPI JSON: <http://localhost:8080/v3/api-docs>
- Health: <http://localhost:8080/actuator/health>
- Liveness: <http://localhost:8080/actuator/health/liveness>
- Readiness: <http://localhost:8080/actuator/health/readiness>


Domain is plain Java. The REST adapter calls `TransactionHistoryUseCase`; the application service delegates to `TransactionHistoryProvider`; and `MockTransactionHistoryAdapter` currently supplies deterministic synthetic data. A later MuleSoft or core-banking adapter can replace that provider without changing the HTTP contract. ArchUnit verifies these dependency boundaries.


```bash
curl -i -X POST http://localhost:8080/open-banking/v1/accounts/transactions \
  -H 'Content-Type: application/json' \
  -H 'X-Api-Key: poc-key' \
  -H 'TPP-ID: TPP-00042' \
  -H 'Provider-ID: BANK-VN-01' \
  -H 'Request-ID: req-poc-001' \
  -H 'Request-Datetime: 2026-10-01T08:29:54Z' \
  -H 'JWS-Signature: poc-not-verified' \
  --data '{"consentId":"CNS-001","accountId":"ACC-001","fromDate":"2026-09-01","toDate":"2026-09-30","page":1,"pageSize":50}'
```

Use `ACC-404` for the contract `ACCOUNT_NOT_FOUND` response and `ACC-500` for `INTERNAL_ERROR`. Omitting `Request-ID` generates a UUID. Authentication and JWS headers are contract-required, but their contents are intentionally not verified in this POC.

```bash
docker build -t open-banking .
docker run --rm -p 8080:8080 -e PORT=8080 open-banking
```

## Render

Create a Render Web Service from this project directory and choose Docker as the runtime. Use `/actuator/health` as the health-check path. Render supplies `PORT`; no database, Kafka, secret, or external service is required for startup.

## Current scope

Only Transaction History is implemented. Responses are mocked as an implementation detail. There is no database, Kafka, OAuth server, JWS verification, mTLS, MuleSoft integration, or core-banking connection yet. Actuator exposes health, info, and metrics.
